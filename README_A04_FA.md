# مدرسه‌یار معلم — A04 Mobile UI (نسخه TEST)

**مبنای این بسته:** نسخه `A03-FIX01` که کاربر روی گوشی نصب و از آن اسکرین‌شات ارسال کرده است.

## چه چیزی تغییر کرده است؟

در A03 داشبورد و «بیشتر» تم آبی‌وسفید و نوار موبایلی داشتند، اما صفحات داخلی صرفاً تغییر رنگ مختصری می‌گرفتند. در A04 برای تمام مسیرهای فعلی معلم که از منو یا پنل اصلی باز می‌شوند، یک لایه مشترک موبایل اعمال می‌شود:

- سربرگ واحد متناسب با بخش فعال (کلاس، حضور، نمرات، تکالیف، آزمون‌ها، گزارش‌ها و ...)
- کارت‌های گرد و فشرده با رنگ آبی و سفید؛ کارت‌های کلاس دیگر به اندازه بسیار بزرگ قبلی نیستند
- فیلدها و دکمه‌های لمسی، فرم‌ها، لیست‌ها، انتخاب‌گرها، جدول‌های قابل اسکرول و پنجره‌های پایین صفحه (Bottom sheet)
- قسمت «تمام ابزارهای پنل وب» نیز تم A04 می‌گیرد و دیگر عمدتاً به تم قدیمی بازنمی‌گردد
- صفحه خانه و بیشتر A03، منوی پایین، ورود با اثر انگشت، ضبط تصویر هنگام بازبودن صفحه، فایل/دوربین/چاپ، منطق سرور و مجوزها حفظ می‌شوند

## نکته فنی و مرز ادعا

این **بازطراحی سراسری نمایش وب در داخل WebView اندروید** است، نه بازنویسی ۱۰۰٪ تمامی ماژول‌ها با کامپوننت‌های بومی Android. صفحات داخلی همچنان HTML/JS اصلی پنل معلم را اجرا می‌کنند و ظاهر آن‌ها با CSS/JS جداگانه فقط در گوشی اصلاح شده است. یعنی قابلیت‌های پنل اصلی حذف یا دوباره پیاده نشده‌اند، اما همه عملیات واقعی (نمره، حضور، تکلیف، بانک سؤال، آزمون و ...) باید روی APK و با حساب آزمایشی تست شوند. برای فرم‌های بسیار خاصِ برخی نسخه‌های سرور ممکن است اصلاح ظاهری جداگانه لازم شود. هیچ ادعای تست موفق روی هاست یا گوشی در این بسته وجود ندارد.

## آزمون محلی

شبیه‌سازی مرورگر با ساختار HTML/CSS استخراج‌شده از سورس قبلی و داده نمایشی: ۱۶ کنترل منطقی پاس؛ سه تصویر `PREVIEW_SIMULATED` تولید شده است. اسکرین‌شات‌ها از اپ واقعی یا حساب واقعی نیستند. ابزار SDK/Gradle اندروید در این محیط نصب نبود، بنابراین کامپایل و نصب APK انجام نشد.

در تمام مراحل هیچ فایلی در `/app/` هاست، `server.mjs`، دیتابیس یا سورس مادر پروژه دستکاری نشده است.
